# v0.1.0 — InferenceX AgentX 4 / 8 并发结果

2026-11-12，本机 8×RTX 5090，SGLang 0.5.20，TP8。两轮均为全新容器、每 lane 10 次预热后正式测量 3600 秒，seed 42，完整 `cc-traces-weka-062126` 语料（峰值上下文 ≤262144 的 220 条轨迹）。

服务口径：原生 MTP（NEXTN，3 草稿 + 1 验证 token），**模拟接受率 AL=2.32**（`match-expected`、`real-draft-token`）；L2 主机缓存每 rank 47 GB（共 376 GB），TTL 与 L3 关闭；CUDA graph 关闭（沿用原服务参数）。

| 指标 | 4 并发 | 8 并发 |
|---|---:|---:|
| 输出吞吐 tok/s | 45.87 | 85.20 |
| 输入吞吐（含缓存）tok/s | 5980 | 9198 |
| 单用户输出速度 平均 tok/s | 14.87 | 13.84 |
| TTFT 平均 / P50 / P90 / P99 s | 1.25 / 0.98 / 1.50 / 8.86 | 29.55 / 12.51 / 72.03 / 271.95 |
| ITL 平均 / P50 / P90 / P99 ms | 68.0 / 65.4 / 76.3 / 101.0 | 75.9 / 70.4 / 82.9 / 139.6 |
| E2E 延迟 平均 / P90 s | 43.1 / 107.6 | 91.2 / 166.8 |
| 缓存读取占比 | 95.8% | 93.8% |
| 其中 GPU / L2 主机命中 | 95.8% / 0 | 34.0% / 59.8% |
| GPU KV 池占用 | 78% | 100% |
| 正式请求 成功 / 失败 | 267 / 0 | 358 / 1 |

上游聚合、失败率校验（阈值 10%）、分布统计和服务指标导出在两轮中全部退出 0。8 并发的 1 次失败为 `ServerDisconnectedError`（0.28%）。

4 并发时 GPU KV 池未满，L2 没有被读取；8 并发时 GPU 池占满，约六成输入 token 由 L2 回载，TTFT 明显升高（回载与预填充排队）。8 并发结束时 L2 的 KV 池已写满（1425344 token/rank），主机可用内存 106 GB。

模拟接受率用于排除接受率波动，不代表模型输出质量或真实接受率。单次运行，未重复。
